# theblakeharrison.com

Personal site for Charles Blake Harrison. Static HTML, CSS and a small amount
of progressive-enhancement JavaScript — no framework.

Deployment, and the two failure modes that have actually bitten this project,
are documented separately in [DEPLOY.md](DEPLOY.md).

---

## Layout

```
source/     edit here — the only place to make changes
dist/       generated by the build; never edit by hand
tools/      build script and a local static server
```

`tools/build.mjs` wipes and regenerates `dist/` from `source/`. Anything typed
directly into `dist/` is destroyed on the next build.

---

## Working on it

```bash
npm install          # once
npm run verify       # lint + typecheck + build — run before every commit
npm run serve        # serve dist/ on http://localhost:8000
```

| Command | What it does |
|---|---|
| `npm run build` | `source/` → `dist/`, content-hashing every referenced asset |
| `npm run lint` | html-validate, stylelint, prettier |
| `npm run typecheck` | `tsc --noEmit`, strict, `checkJs` over the browser JS |
| `npm run format` | rewrite with prettier |
| `npm run serve` | static server with `no-store`, so nothing is cached locally |

## Two things that are easy to break

**Accessibility is at 100 and should stay there.** `--accent` (`#fe5c00`) is
only 3.11:1 on white and fails AA as text. Use `--accent-ink` for orange text
on a light surface, and `--ink` for text on an orange fill. The vivid accent
is for fills, borders and dots only.

**Never gate content behind JavaScript.** A scroll-reveal enhancement once
made every section below the hero invisible. Any animation that hides
something must still render the content with JS disabled.
